Neo4j uses the graph structure to store data and is known as a labeled property graphThe data model Neo4j implements, in which nodes and relationships both carry properties as well as labels and types..

Neo4j stores and organizes data using these four elements:

- Nodes - The fundamental entities in the graph
Relationships - The connections between nodes
LabelsA tag on a node that groups it with other nodes of the same kind. A node can carry more than one. - Categories or types for nodes
PropertiesA named value stored on a node or a relationship. - The attributes of nodes and relationships
