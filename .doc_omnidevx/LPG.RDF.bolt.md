Raw FIBO via n10s: The EDM Council's FIBO is published as OWL ontologies in RDF format (Turtle, RDF/XML). If you loaded raw FIBO with n10s, you would import an RDF schema structure into Neo4j (classes, subclasses, object properties, annotations). This is useful for semantic reasoning, but it is cumbersome to query for daily operations and portfolio look-through analysis.
This Reference Ontology: This package translates FIBO's concepts into a native Neo4j Labeled Property Graph (LPG). Instead of RDF triples, entities become labeled nodes (:Security, :LegalEntity, :Fund, :Listing), and semantic associations become directed relationships (:ISSUED_BY, :HOLDS, :REPRESENTS).
